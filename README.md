# PromptKingAI Next.js starter

## Local run
npm install
npm run dev

## Production
npm run build
npm start

## Hostinger
Use Web App -> GitHub repository.
Hostinger should detect Next.js from package.json.
The required start script is included.

## Current sample
- Homepage
- Dynamic prompt detail route: /prompt/[slug]
- Copy Prompt button
- No likes or like count on website
- Responsive layout
- Placeholder data/images ready to replace with your existing Prompt King backend/API
